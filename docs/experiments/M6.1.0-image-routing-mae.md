# M6.1.0 — learned versus fixed GMM image routing

Compare two randomly initialized MoE-MAEs on the same 18-regime BDD stream. Both use image-level **top-4 routing with
four experts**: every expert processes every visible token, weighted by its image probability. The learned arm uses the
existing V-MoE-style gate; the fixed arm uses the M6.0.0 GMM. This isolates the routing strategy at matched expert
computation. Neither arm filters incoming images.

## Frozen protocol

| Factor | Setting |
| -- | -- |
| Dataset | Verified existing 61,555-image BDD train cache; four scenes and defined time/weather attributes |
| Training IDs | Same 60,955 IDs after reserving the existing 200-image support, balanced-query and natural-query panels |
| Stream | Daytime → dawn/dusk → night; within each, clear → partly cloudy → overcast → rainy → snowy → foggy |
| Exposure | Two complete regime walks, shuffling within blocks each pass; five paired seeds 0–4 |
| Batch/budget | 64 images, 952 updates/pass, 1,904 updates/arm; no half-batch admission |
| Encoder | 64 px, patch 8, width 96, four blocks, three attention heads; four experts in zero-based blocks 2/3 |
| Decoder/objective | Dense MAE decoder, width 64/depth 2/heads 4, mask ratio 0.75, normalized pixel targets |
| Initialization | From scratch; identical encoder, expert and decoder parameters within each seed |
| Optimizer | AdamW, LR 0.001, weight decay 0.05, gradient clip 1.0; constant LR, no boundary restart |
| Pairing | Same image IDs/order, image-keyed augmentation and masks; step-keyed router noise only in learned arm |
| Runtime | CPU, four threads/worker, two independent seed-pair workers; arm order alternates across seeds |

As in the previous regime experiment, each pass first retains 60,928 IDs from its seeded permutation, then stably groups
them by regime. The remaining 27 IDs are excluded for that pass. This preserves membership and avoids systematically
dropping the last, rare regimes. Blocks are concatenated before batching, so a small number of batches straddle
boundaries. `stream_manifest.json` records the exact spans, mixed batches, retained hashes and dropped IDs for every
seed/pass.

The learned gate averages the normalized visible tokens entering each MoE MLP, including CLS, independently at each
layer. It uses full softmax, training logit-noise standard deviation 1/4, and the existing importance-balancing loss
with coefficient 0.01. With all four experts selected, expected-load balancing is identically zero. Evaluation gates are
clean.

The fixed arm has **no router parameters** and no balancing objective. The M6.0.0 probability row is joined by the
original image filename, detached, normalized for float32 roundoff, and reused over all tokens, layers, augmentations
and masks. The saved sklearn pipeline is checked against all cached training probabilities before training. This remains
an intentional all-data look-ahead baseline: the GMM saw train, validation and test images when fitted. Its frozen ViT
is not part of the trainable MAE, and the cached embedding/GMM preprocessing cost is excluded from MAE update timing.

All shared parameters match exactly within seed. The learned model has 637,864 parameters; the fixed model has the same
637,088 shared parameters, with the 776 learned gate parameters removed.

## Health, per-regime retention and step routing

Measurements run at initialization, every 50 updates, each regime exit, and the endpoint. The block-exit checkpoint is
the first completed minibatch containing the last image from that block. Scene kNN and standardized linear probes run at
updates 0, 476, 952 and 1,904, using the original support/query recipes.

The recorded health suite includes natural and balanced reconstruction MSE, RankMe, directional feature variance and
off-diagonal covariance, uniformity, fixed-view alignment, CKA/cosine drift, clean router entropy, mean expert mass,
argmax representation and route changes. Training records reconstruction, raw/weighted auxiliary loss and gradient
norms.

Per-regime reconstruction uses independent official BDD **validation** panels, leaving every existing train/evaluation
ID unchanged. Up to 32 images are selected deterministically per regime, totaling 452. Five rare panels are smaller:
daytime-foggy 5, dawn/dusk-foggy 1, night-partly-cloudy 5, night-overcast 18, and night-foggy 7. Fixed image-keyed views
and four mask draws are reused across checkpoints, arms and seeds. Small-panel results remain descriptive.

For each regime/pass, record MSE immediately after its block and at pass end. The primary deterioration measure is the
signed difference **pass-end MSE minus block-exit MSE**; negative means improvement. Aggregate within seed across
regimes that have subsequent training updates. The final block has no later exposure and is excluded from this
aggregate. Also record endpoint-minus-best-after-exit and worst-minus-exit as secondary summaries. Averages and
descriptive paired 95% t intervals use the five training seeds as replicates; validation frames, masks and checkpoints
are not replicates.

For **every gradient step and each MoE layer**, `training.jsonl` contains:

- `l{layer}_batch_top1_expert`: `argmax(mean(image_probabilities, batch))` from the actual noisy training forward.
- `l{layer}_mean_probabilities`: all four minibatch-mean weights, and per-image argmax counts.
- `l{layer}_expert_grad_norm`: four actual unclipped expert gradient norms; router gradient norm is null in the GMM arm.
- Exact per-regime sums of individual image probabilities, including mixed boundary batches.
- Sample IDs, regime counts and hashes of image order, augmented views and mask noise.

Top-1 is a weighting summary: all four experts execute. Gradient norms distinguish weighting from actual task gradients;
AdamW momentum/decay can also move parameters. Learned expert IDs are inspected within a seed rather than averaged
across independent seed permutations. GMM expert n is associated with the same frozen component n at both layers.

## Runtime checks before the full run

The local update benchmark included per-image augmentation, masking, backward, clipping, optimizer updates, routing
readouts and expert gradient norms. Mean seconds/update for learned/GMM were 0.0499/0.0471 on four-thread CPU versus
0.0563/0.0548 on Metal. CPU was selected. This single-worker microbenchmark is separate from contended full-run timings.

All 57 focused MoE/experiment tests passed, covering weighted expert sums and gradients, absence of learned GMM routers,
matched shared initialization, correct minibatch top-1 semantics, evaluation isolation, exact resume for both arms and
end-to-end paired analysis. The real-BDD two-worker pilot completed both arms for two seeds with 12 updates each. The
repository's pinned pre-commit checks and dependency audit passed before the full experiment was launched.

## Results — 2026-11-04

All ten arms completed 1,904 updates: 19,040 total gradient updates and 1,218,560 training-image exposures. The complete
trace audit matched saved shared initial parameters, every image order/augmentation/mask, all regime-stream hashes, and
the original GMM probabilities at every fixed-router update. All 38,080 layer-level top-1 records are present. Across
380 saved GMM evaluation panels, probabilities remained fixed and equal to the original image table. All 36 regime exits
per arm were evaluated. Source and GMM fingerprints remained unchanged. See `verification.json` and its re-runnable
`verify_run.py` in the output directory.

| Outcome (mean across five seeds) | Learned top-4 | Fixed GMM | Paired GMM − learned, descriptive 95% interval |
| -- | -- | -- | -- |
| Natural held-out MSE | 0.71652 | 0.71887 | +0.00235 [−0.00575, +0.01045] |
| Balanced held-out MSE | 0.68839 | 0.69122 | +0.00283 [−0.00681, +0.01246] |
| Pass 1 mean regime endpoint-minus-exit MSE | −0.00599 | −0.00473 | +0.00126 [−0.01199, +0.01451] |
| Pass 2 mean regime endpoint-minus-exit MSE | +0.01180 | +0.00844 | −0.00336 [−0.01059, +0.00386] |
| Balanced linear-probe accuracy | 38.6% | 37.9% | −0.7 pp [−4.0, +2.6] |
| Balanced kNN accuracy | 35.1% | 34.9% | −0.2 pp [−4.65, +4.25] |
| Final RankMe | 16.61 | 16.44 | −0.17 [−1.59, +1.25] |
| Final normalized clean routing entropy | 0.97098 | 0.03476 | −0.93622 [−0.96109, −0.91135] |

The GMM endpoint reconstruction MSE is 0.33% higher on average; its paired interval includes zero. The second pass shows
positive average reconstruction deterioration after regime blocks in both arms. GMM has a smaller point estimate in four
of five seed pairs, but that paired interval also includes zero. The first-pass signed averages are slightly negative
because subsequent training can continue improving earlier regimes. No clear performance or retention benefit is
established by this run.

Routing behavior differs strongly. Learned image distributions remain near uniform, whereas GMM weights switch between
the day-associated experts 2/3 and night-associated experts 0/1. The actual gradient traces show the corresponding
changes in learning intensity. This demonstrates structured expert weighting, without by itself proving useful semantic
specialization. Shared dense/attention parameters still learn from every regime.

These conclusions are conditional on this small from-scratch model, two passes, five seeds, fixed evaluation panels and
the learned arm's existing importance balancing. In particular, several rare-regime panels contain very few images. The
notebook exposes every recorded standard health signal, individual seed pairs, both MoE layers, and per-regime
trajectories so the aggregate outcomes can be inspected rather than inferred from routing entropy alone.
