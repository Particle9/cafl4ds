# M6.3.0 Day+dusk to night forgetting

Train on all 61,555 images in the existing four-scene BDD100K training cache. Each seed shuffles the 34,187 daytime and
dawn/dusk images together and presents each once, then shuffles and presents the 27,368 night images once. Batch size is
64 and each phase retains its last short batch. The switch is after update 535 and training ends at update 963. Five
paired seeds (0–4) use identical per-seed orders, augmentations, and mask priorities across variants. AdamW state
carries across the switch.

| Arm | Encoder routing and merge | Trainable parameters | Approx. forward GFLOPs/image |
| -- | -- | -- | -- |
| V-MoE top-4 | Learned image-level gate over four MLP experts in the last two blocks | 637,864 | 0.0328 |
| V-MoE top-1 | Learned image-level gate selecting one MLP expert per image in the last two blocks | 637,864 | 0.0253 |
| GMM MLP | Fixed image weights over four MLP experts in the last two blocks | 637,088 | 0.0328 |
| GMM full trunks | Four independent patch embeddings and ViT encoders with a token mixture before one decoder | 1,386,752 | 0.0638 |
| GMM split after two | Shared patch embedding and two blocks with four private suffixes, then a token mixture and one decoder | 863,456 | 0.0410 |
| GMM full trunks and private decoders | Four independent encoder–decoder pairs with a final prediction mixture | 1,656,704 | 0.1012 |

Every encoder path uses four transformer blocks and width 96. The paired initialization uses identical tensors in the
two V-MoEs and the compatible components of the GMM MLP arm. The split prefix matches the GMM MLP prefix. Its four
private suffixes match their corresponding full trunks. The two full-trunk variants share their initial encoder tensors.
The shared decoder and private decoder 0 use the same initial tensors as the MLP baselines. The FLOP estimates count
patch projection, attention matrix multiplies, MLP and decoder projections with two FLOPs per multiply-add. The arms
match image exposure and their executed computation varies.

The GMM arms reuse the image posteriors from M6.0.0 and broadcast them over tokens or predicted patches. All branches
use the same visible patch positions per image. The final prediction mixture computes masked MSE against one patch
target after weighting the four predictions. The learned arms use the existing V-MoE auxiliary loss and an AdamW rate of
0.001. The GMM arms use `0.001 × min(1, 4q_e)` for private parameters, where `q_e` is the mean fixed posterior for
expert `e` in the current minibatch. Shared parameters use 0.001. Private decoders are in the same rate groups as their
encoders.

The fixed official validation panel reuses the M6.2.0 time-by-weather strata. It contains 165 daytime images, 161
dawn/dusk images, and 126 night images. Each image contributes an average over four fixed augmentations and 75% masks.
The day+dusk aggregate gives each panel image equal weight. Reconstruction MSE is calculated in per-patch normalized
target space. Evaluation runs at initialization, every 50 updates, immediately before the first night update,
immediately after it, and at the endpoint.

The primary outcome is the increase in day+dusk MSE from the switch to the final checkpoint. The notebook shows the
corresponding absolute curve, separate daytime and dawn/dusk curves, peak change among evaluated checkpoints, and the
night curve. Paired differences and descriptive 95% Student-t intervals use seeds as the replicate unit.

Run from the repository root.

```bash
MPLBACKEND=Agg OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 VECLIB_MAXIMUM_THREADS=4 \
caffeinate -i .venv/bin/python -u -m scripts.run_day_night_experiment
```

Outputs go to `outputs/m6_3_0`. The run records the protocol, model source snapshots, paired sample and mask hashes,
optimizer checkpoints, the exact pre-night checkpoints, and audit results. Open `notebooks/m6_3_0.py` with marimo or use
the exported report.

The six-arm pilot used 326 real training images in each phase. It verified the short batches, boundary evaluations,
matched initial tensors, matched views and masks, fixed routing and the capped rate vectors. The 69 focused tests also
passed, including the private-decoder output mixture and an exact optimizer resume at the switch.

## Results

All 30 runs completed. The audit checked 28,890 updates and 24,075 GMM learning-rate vectors. Each run presented all
61,555 images once with the matching seed-specific views and masks. GMM AdamW counters advanced through the phase
boundary. Both full-trunk variants had the same initial encoders.

| Arm | Day+dusk at switch | Day+dusk final | Endpoint Δ MSE | Peak Δ MSE | Night final |
| -- | -- | -- | -- | -- | -- |
| V-MoE top-4 | 0.80501 | 0.78339 | -0.02162 | 0.04058 | 0.70244 |
| V-MoE top-1 | 0.80641 | 0.79909 | -0.00732 | 0.05452 | 0.71813 |
| GMM MLP | 0.80038 | 0.78798 | -0.01240 | 0.04457 | 0.70967 |
| GMM full trunks, shared decoder | 0.82334 | 0.85253 | +0.02919 | 0.15455 | 0.80483 |
| GMM split after two | 0.80734 | 0.80181 | -0.00552 | 0.04970 | 0.72203 |
| GMM full trunks, private decoders | 0.83268 | 0.82443 | -0.00825 | 0.00838 | 0.80492 |

Top-4 V-MoE has the lowest mean final day+dusk and night MSE. The capped GMM MLP arm’s mean endpoint change is 0.00923
higher than top-4 V-MoE, with a paired descriptive 95% interval of [−0.00418, +0.02264].

The full-trunk model with a shared decoder shows a mean endpoint increase of 0.02919. Adding private decoders lowers the
endpoint change by 0.03743 relative to those same full trunks (paired interval [−0.04927, −0.02559]) and reduces the
mean measured peak increase to 0.00838. The two full-trunk arms finish near 0.805 night MSE, versus 0.702 for top-4
V-MoE.

The notebook includes all paired contrasts, individual seed traces, and the separate daytime and dawn/dusk curves.
